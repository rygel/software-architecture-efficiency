# Version 1.4.0 evaluation outcome

Date: 2026-11-07. This version rewrites the skill description so that it loads for architecture-efficiency questions and stays out of ordinary coding tasks, adds a conditional non-WebView client option to hybrid reviews, inlines the complete-stack checklist, and adds a rule that every server size, memory or CPU target, price and saving is either sourced or written as "unknown until <named measurement or page>".

## What was run

Both runs used the skill as a project skill in an otherwise empty folder, with the rest of the machine's skills, plugins, MCP servers and rule files switched off or not loaded. The tested `SKILL.md` is identical to the released one except for the `metadata.version` line (`1.3.0` while testing, `1.4.0` in the release). LF-normalized SHA256 of the tested file: `131ebf8263b73b4cd032f87e83bead19b96ebf0e528987603228a0b9a200186e`; of the released file: `f7fcc71fd60228448a486abf02968a0d07d029053323c96655eb6b711603201a`.

| Tool | Model | Runs | Skill loaded when it should | Skill loaded when it should not |
| --- | --- | --- | --- | --- |
| Claude Code 2.1.319 (`claude -p`, read-only tools) | Claude Opus 5.5 | 22 (9 prompts x 2, plus Cases 08 and 10 x 2) | 10 of 10 | 0 of 8 |
| OpenCode 2.2.5 (OpenCode Go, read-only agent) | DeepSeek V4.1 Flash | 9 (9 prompts x 1) | 5 of 5 | 0 of 4 |

The five should-load prompts: Electron-to-Tauri RAM question, Docker/Redis hosting bill, Python-to-Rust rewrite, a Next.js app out of memory on a 4 GB VPS, and a desktop client embedding a web engine. The four should-not-load prompts: reverse a linked list, fix a Go index panic, add a Redis cache with redis-py, write a Dockerfile.

Claude Code Cases 08 and 10 (two runs each, [responses retained](responses-v1.4.0.md)) were scored by the authoring agent with keyword checks plus a read of the passages that matter:

| Case | Outcome | Observed behavior |
| --- | --- | --- |
| 08 | Pass, both runs | Rejects "fully native-widget because the core is Rust", names the WebView, treats the 45 MiB Rust-process figure as not a full-process-tree measurement, and lists non-WebView toolkits as conditional. |
| 10 | Pass, both runs | Treats the Tauri client as baseline, proposes a conditional non-WebView client, rejects the shared SQLite file for the remote transactional and failover requirements and keeps old-client compatibility. |

The six server-track Claude Code answers (T2, T3 and H1, two runs each) contain no price, server size or saving without a source.

In the nine OpenCode answers, one server-size figure had no source ("add 1-2 GB of swap" in the Next.js answer).

Client-reported cost of the Claude Code runs was 3.54 USD in total over 22 runs (plan usage, not a per-call charge). The OpenCode runs used about 0.34 USD at list price by the token-based estimate, which counts cached input at the full input price and so is an upper bound.

## Earlier runs for this version

During development the same skill text, on the same OpenCode model, was also run on 15 should-load and 12 should-not-load prompts (3 repetitions of 5 and 4 prompts) and on Cases 01, 05, 06, 08, 10 and 11 (3 repetitions each). Skill loaded on 15 of 15 and 0 of 12; the six cases all met the checks; a size-and-price prompt set produced one unsourced figure in 12 runs after the sourcing rule was added. The description before this version loaded on 8 of 15. The answers from those runs were not retained.

## Not valid

OpenCode Cases 01, 05, 06, 08 and 10 were also run in the final batch and are not counted. The Windows `.CMD` launcher cut each multi-line prompt at the first line break, so the model received only the "Request:" line and replied that no application was in the workspace. Case 11 was not run. These were not repeated.

## Limits

Author-scored, synthetic prompts, small repetition counts, one Claude model and one OpenCode model. Codex was not run on a model; its skill discovery was checked without a model. The trigger result says the skill loaded, not that the advice is correct. The cases are fixture evidence and do not replace a real desktop or server benchmark.
